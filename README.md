### Featured Project

**[AI Product Data Extractor — Flexikitch.com.au](https://github.com/sahil0804/ProductDataAgent-Flexikitch.com.au)**
A Streamlit-based RAG application built with a team of four to automate extraction of product specifications from supplier PDFs into Shopify-ready Excel files, replacing manual data entry for a retail product catalog.

- Led the AI extraction layer: designed and iterated on GPT-4o/GPT-4o-mini prompts to map inconsistent supplier PDF fields (e.g. "SKU" vs. "Product Code" vs. "Product ID") to a fixed Shopify schema
- Handled unit standardization (dimensions, weights) and field mapping across spec sheets with no consistent layout or structure across suppliers
- Built in cost estimation (token-based API cost preview) and statistical outlier detection (IQR / z-score) to flag extraction errors before export
- Stack: Python, Streamlit, LangChain, OpenAI API, Pandas, OpenPyXL
